Как это считает

Поле магнитов. Цилиндры и кольца с осевой намагниченностью — точно, по Дерби–Олберту (эллиптические интегралы). Блоки, сегменты дуги, диаметральные цилиндры — как равномерно намагниченные многогранники: каждая грань несёт магнитный «заряд» σ = M·n, поле заряженного многоугольника берётся в замкнутом виде (телесный угол + логарифмы по рёбрам). Криволинейные грани — фасетками. Шар — точный диполь. Проверено против прямого численного интегрирования: расхождение меньше 0,01%.

Сила на катушку — сила Лоренца по нитям, на которые разбит пучок (Гаусс по отрезкам). Сила на магнит — интеграл σ·B по заряженным граням. Оба метода сверены друг с другом (третий закон Ньютона сходится лучше 1%).

Сталь. Бесконечная плита с μ→∞ — методом изображений (точно, пока плита не насыщена). Две параллельные плиты — цепочка отражений. Стакан с ярмом в войсколе — по магнитной цепи, это оценка ±30%. Замкнутые ярма конечной формы и насыщение не считаются — это следующий шаг (осесимметричный FEM в браузере).

Km — константа двигателя: сила (или момент) на корень из ватт меди. Не зависит от числа витков и диаметра провода — они только раскладывают Km под напряжение. Для 3-фазного BLDC: Km = Kt/√(1,5·Rф), Kt — момент на пиковый ток фазы при синусной коммутации.

BLDC. Момент считается для одной катушки на электрическом периоде (ротор поворачивается), остальные катушки получаются симметрией; фазы раскладываются звездой пазов. Железа в статоре нет (беззубцовый/безжелезный), спинки ротора и статора — плиты-зеркала. Индуктивность — по Нейману/Максвеллу с GMD пучка (±10%), взаимная индуктивность фаз не учтена.

Шаровой мотор. Для каждой катушки — вектор момента на ротор на ампер-виток; матрица 3×N; минимальная мощность на заданный момент даёт Km по направлениям (сингулярные числа). Карта — Km слабейшей оси при наклоне оси ротора.

Не учитывается: размагничивание магнитов полем катушки, вихревые токи и потери в стали, температура магнитов (Br при 20 °C), масса каркасов. Сетка разбиения катушки на нити влияет на точность на 1–2% — на вкладке «Сцена» число нитей подбирается по размеру пучка.
