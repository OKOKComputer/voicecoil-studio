Нажмите на строку, чтобы посмотреть разрез. Ровность: насколько сила в худшей точке хода близка к лучшей.

Поле магнитов считается точно: каждый магнит заменяется эквивалентным поверхностным током, поле — через эллиптические интегралы (Derby–Olbert). Сталь учитывается двумя способами: идеальная плита под магнитами — методом изображений (точно для ненасыщенной плиты), стакан с ярмом — по магнитной цепи с утечкой и выпучиванием поля, это оценка ±30%.

Не учитываются: размагничивание поля катушкой, насыщение плиты, индуктивность и вихревые токи на высоких частотах, масса каркаса. «Свободная форма» — лучший набор ячеек при одинаковом токе; «градиентная обмотка» — теоретический потолок, если плотность тока в каждой точке пропорциональна полю.
